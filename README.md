# DS4200 Project: Examining Student Learning Traces in the Duolingo App
Janet Liu, Richy Xie, Drew Kuhn, Lauren Xiao

### About the Project
Duolingo is the world’s most popular language learning app. Founded by Luis von Ahn at Carnegie Mellon University in 2011, the app has since grown to hundreds of millions of active users. The app offers free, engaging language mini-lessons while gamifying features to build daily habits. Through bite-sized lessons, the app breaks down unfamiliar words and concepts using research-backed methods like spaced repetition, active retrieval, and adaptive difficulty. While the app originally started for language learning, it has since expanded to include subjects like math, music, and chess. Beyond a fun and interactive user interface, Duolingo works towards a broader mission of making high-quality language education accessible to anyone with a smartphone, regardless of socioeconomic status. Using a dataset of student learning traces in the app, we can better understand how users interact with the app, whether lessons are effective, and what user characteristics are. Ultimately, our goal is to explore how usage of the Duolingo app is related to language learning. 

### Files
- `dataset_creation.ipynb`: randomly selects 10,000 rows from the raw dataset
- `analysis.ipynb`: contains the data analysis and visualizations
- `analysis_dataset.csv`: sampled dataset for analysis
